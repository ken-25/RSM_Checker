# 避雷設備 回転球体法簡易検討3D可視化ツール (Rolling Sphere Method Checker)

## 概要
本ツールは、避雷設備設計における**回転球体法（Rolling Sphere Method）**に基づく保護範囲の検討を、Webブラウザ上で簡易的に行える3Dシミュレーションツールです。
JIS A 4201:2003 に準拠した保護レベル（球体半径）を設定し、複数の受雷部（突針）の配置に対して、球体がどのように接触するかを立体的に可視化します。

平面図だけでは把握しにくい「高さ方向の保護範囲」や「球体の侵入経路」を直感的に確認できるため、初期段階のレイアウト検討や、関係者への説明資料作成に役立ちます。

## 特徴
*   **3D可視化**: Three.js を使用し、受雷部と回転球体の関係を立体的に表示します。
*   **保護レベル設定**: 保護レベル I～IV（半径 20m, 30m, 45m, 60m）の切り替えが可能です。
*   **受雷部配置**: 最大4本までの受雷部（突針）に対し、任意の座標（X, Y, 高さZ）を設定可能です。
*   **判定ロジック**: 設定されたすべての受雷部に球体が接触するかどうかを自動判定し、成立する場合の球体中心位置や地面からの距離を計算します。
*   **インストール不要**: Webブラウザのみで動作します。

## 使い方
1.  **条件設定**: 画面左側のパネルで、保護レベル（球体半径）を選択します。
2.  **受雷部設定**: 「受雷部 有効」にチェックを入れ、各ピンのX座標、Y座標、高さ(Z)を入力します。
    *   *注: 画面上の入力は建築座標系（Z軸＝高さ）ですが、内部計算はY軸＝高さとして処理されています。*
3.  **結果確認**:
    *   **判定結果**: すべての有効な受雷部に球体が接する場合、球体が表示されます。
    *   **数値情報**: 球体中心の座標や、地面から球体最下点までの距離が表示されます。

## 計算アルゴリズム詳細

本ツールでは、与えられた複数の点（受雷部先端）すべてに接する半径 $R$ の球体を求めるために、以下のアルゴリズムを採用しています。

### 1. 座標系の扱い
UI上では一般的な建築・CAD座標系に合わせて **Z軸を高さ** としていますが、内部の3D計算エンジン（Three.jsおよび計算ロジック）では **Y軸を高さ** とする座標系を使用しています。
*   入力: $(X, Y, Z_{height})$
*   内部変換: $x=X, y=Z_{height}, z=Y$

### 2. 球体中心の算出ロジック
有効な受雷部の点集合 $P = \{p_1, p_2, ..., p_n\}$ に対し、以下の手順で最適な球体中心 $C$ を探索します。

1.  **組み合わせの列挙**:
    点集合 $P$ から、1点、2点、または3点の組み合わせ（サブセット）をすべて生成します。

2.  **球体中心の計算**:
    各組み合わせについて、それらを通る半径 $R$ の球体中心を幾何学的に計算します。
    *   **3点支持の場合**: 3点を通る外接円の中心から、法線方向にオフセットした位置を計算。
    *   **2点支持の場合**: 2点間の垂直二等分面上にあり、かつ2点からの距離が $R$ となる軌跡の中で、最も「高さ（内部Y座標）」が高い点を採用。
    *   **1点支持の場合**: その点の直上（距離 $R$）を計算。

3.  **妥当性検証 (IsTouchingAllPoints)**:
    算出された球体について、**「現在有効なすべての受雷部が、その球面上にある（接触している）か」** を検証します。
    *   許容誤差（tolerance）を考慮し、すべての点 $p_i \in P$ について、球体中心からの距離が $R$ とほぼ等しいかを確認します。
    *   *本ツールでは現在、「指定したすべての受雷部が球体を支えている状態（全点接触）」のみを有効解として扱います。一部の点だけが接し、他の点が球の内部や外部にあるケースは対象外となります。*

4.  **最適解の選択**:
    条件を満たす球体候補が複数ある場合、以下の優先順位で最適解を選定します。
    1.  **支持点数が多い**: より多くの点によって幾何学的に定義される解を優先（3点支持 > 2点支持...）。
    2.  **高さが高い**: 地面からの距離（クリアランス）が最も大きくなる解を採用。

### 3. 主要ファイル構成
*   `index.html`: UI構造およびパラメーター入力フォーム。
*   `main.js`: 3Dシーンの構築（Three.js）、UIイベントのハンドリング、座標変換。
*   `sphereCalculation.js`: 純粋な幾何計算ロジック。`calcSphereFixedRadius` 関数がアルゴリズムの中核です。
